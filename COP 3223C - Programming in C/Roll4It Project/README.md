# Roll4It

Roll For It dice game, built up over the COP 3223C assignments. The current
`roll4it.c` is the Assignment 3 version: a playable game loop with cards,
dice, and input validation.

## Build and run

From this folder:

```
gcc -Wall -o roll4it roll4it.c
./roll4it
```

## Submitting

Each submitted zip is saved in `../Submissions`. Upload the zip for the
current assignment to Webcourses.
