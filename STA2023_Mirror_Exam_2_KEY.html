Question 3 (8 points) — Cars per Household

(a) P(x) = frequency ÷ total; total = 12 + 28 + 32 + 8 = 80

\[P(0)=\frac{12}{80}=0.1500\qquad P(1)=\frac{28}{80}=0.3500\qquad P(2)=\frac{32}{80}=0.4000\qquad P(3)=\frac{8}{80}=0.1000\]

Check: 0.1500 + 0.3500 + 0.4000 + 0.1000 = 1 ✓

(b) x across (0, 1, 2, 3), P(x) up; a vertical bar above each x with heights 0.15, 0.35, 0.40, 0.10; tallest at x = 2; label both axes.

(c)

\[\mu=\sum x\,P(x)=0(0.15)+1(0.35)+2(0.40)+3(0.10)=0+0.35+0.80+0.30=1.45\]
μ = 1.45 cars

Interpretation: over many households in this neighborhood, the average number of cars per household is about 1.45.

(d) σ = √Σ(x − μ)²·P(x) with μ = 1.45

\[(0-1.45)^2(0.15)=2.1025(0.15)=0.3154\qquad (1-1.45)^2(0.35)=0.2025(0.35)=0.0709\]
\[(2-1.45)^2(0.40)=0.3025(0.40)=0.1210\qquad (3-1.45)^2(0.10)=2.4025(0.10)=0.2403\]
\[\sigma^2=0.3154+0.0709+0.1210+0.2403=0.7476\qquad \sigma=\sqrt{0.7476}=0.86\]
σ ≈ 0.86 cars

(Unrounded: σ² = 0.7475, σ = 0.8646; either rounds to 0.86.)

Question 4 (8 points) — Reading Habits (binomial, n = 8, p = 0.35, 1 − p = 0.65)

\[P(x)={}_{8}C_{x}\,(0.35)^{x}(0.65)^{8-x}\]

(a) exactly 2

\[{}_{8}C_{2}=\frac{8\cdot 7}{2\cdot 1}=28\qquad P(2)=28(0.35)^2(0.65)^6=28(0.1225)(0.0754)=0.2587\]
0.2587

(b) at most 2 → x = 0, 1, 2 (the 2 is IN)

\[P(0)=(0.65)^8=0.0319\qquad P(1)=8(0.35)(0.65)^7=0.1373\qquad P(2)=0.2587\]
\[P(X\le 2)=0.0319+0.1373+0.2587=0.4279\approx 0.4278\]
0.4278 (0.4279 if you add the rounded values — both accepted)

(c) at least 1 → 1 − P(0)

\[P(X\ge 1)=1-(0.65)^8=1-0.0319=0.9681\]
0.9681

(d) n = 300

\[\mu=np=300(0.35)=105\qquad \sigma=\sqrt{np(1-p)}=\sqrt{300(0.35)(0.65)}=\sqrt{68.25}=8.26\]
μ = 105, σ ≈ 8.26

Exact values: P(2) = 0.2587, P(0) = 0.0319, P(1) = 0.1373, P(X ≤ 2) = 0.4278.
