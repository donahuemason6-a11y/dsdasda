# Artist photos

Drop one image per artist in this folder. The page looks for the exact file
named in `js/data.js` next to each set (for example `img/jid.jpg`). Until a
file exists, that artist shows a monogram tile instead, so missing photos
never break the page.

Tips
- Square crops (for example 600 x 600) look best. Faces centered.
- JPG or PNG. Keep each under ~200 KB so the page stays fast on phones.
- To use a different filename, change the `photo` value for that artist in `js/data.js`.
