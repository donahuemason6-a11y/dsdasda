CH 4 — PROBABILITY

Basics

  • Probability = long-run proportion of times an outcome happens. 0 ≤ P(E) ≤ 1; all outcomes add to 1. Unusual = P < 0.05.
  • Sample space S = all possible outcomes; event = some of them.
  • Classical (equally likely): P(E) = N(E) ÷ N(S). Empirical (from data): P(E) ≈ frequency ÷ total. Subjective = educated guess.
  • Disjoint = can't both happen (no overlap). Independent = one doesn't change the chance of the other.
NOT: P(Ec) = 1 − P(E)
OR: P(E or F) = P(E) + P(F) − P(E and F)  (disjoint → P(E and F) = 0)
AND (independent): P(E and F) = P(E)·P(F)
AND (general): P(E and F) = P(E)·P(F | E)
GIVEN: P(F | E) = P(E and F)P(E) = N(E and F)N(E)
AT LEAST ONE: P(at least 1) = 1 − P(none)
Independent test: P(F | E) = P(F)? yes → independent

Contingency table (two-way table) ★Q1

  1. Add row totals and column totals; grand total = N.
  2. "is A" → (A's total) ÷ N.
  3. "A or B" → P(A) + P(B) − P(both) (subtract the overlapping cell).
  4. "A and B" → the one cell ÷ N.
  5. "A given B" → cell ÷ (B's row or column total). Divide by the GIVEN group only.
Q: "Employment status of 78 residents: Full-time M 22 / F 18; Part-time M 6 / F 10; Unemployed M 3 / F 2; Not in labor force M 5 / F 12. Males = 36, Females = 42."
Row totals: full-time 40, part-time 16, unemployed 5, not in labor force 17.
(a) P(male) = 36/78 = 0.4615
(b) P(part-time) = 16/78 = 0.2051
(c) P(male OR unemployed) = 36/78 + 5/78 − 3/78 = 38/78 = 0.4872
(d) P(female AND not in labor force) = 12/78 = 0.1538
(e) P(part-time | female) = 10/42 = 0.2381 (divide by females only)
Q: "P(speeder pulled over) = 0.8; P(ticket | pulled over) = 0.9. P(pulled over AND ticket)?" A: 0.8 × 0.9 = 0.72
Q: "P(24-yr-old male survives the year) = 0.9986. P(at least one of 1000 dies)?" A: 1 − 0.99861000 = 1 − 0.2464 = 0.7536
Q: "One card: P(king or diamond)?" A: 4/52 + 13/52 − 1/52 = 16/52 = 0.3077
Q: "Coin flipped twice: sample space? P(two heads)? P(at least one tail)?" A: S = {HH, HT, TH, TT}; 1/4 = 0.25; 3/4 = 0.75.
Q: "Pick 2 of 4 friends (A, B, S, D): P(A and B)? P(B goes)?" A: S = {AB, AS, AD, BS, BD, SD} → 1/6; 3/6 = 0.5.
Q: "Is {A 0.40, B 0.20} a valid probability model?" A: No — sum 0.60 ≠ 1. "{A −0.10, …}" → No — negative.
Q: "200 people: 22 carpool, 5 walk. P(carpool)? Unusual to walk?" A: 22/200 = 0.11; walk 5/200 = 0.025 < 0.05 → unusual.
Q: "Die: P(6)? P(6 | even)?" A: 1/6; given even → {2,4,6} → 1/3 (changed → dependent).
Q: "Are 'widowed' and 'female' independent? P(widowed) = 15.0/271.7 = 0.0552, P(widowed | female) = 11.5/138.1 = 0.0833." A: 0.0833 ≠ 0.0552 → dependent.
Q: "Two 24-yr-old males both survive (0.9986 each)?" A: independent → 0.9986² = 0.9972. Rule of thumb: sample < 5% of population → treat as independent.

CH 5 — DISCRETE RANDOM VARIABLES

Probability distribution ★Q2, Q3

  • Discrete = countable values (0, 1, 2 …); continuous = any value in an interval (measured).
  • Probability distribution = every value of X with its P(x) (table, graph, or formula).
VALID if: (1) each 0 ≤ P(x) ≤ 1  and  (2) Σ P(x) = 1
μX = Σ [ x · P(x) ]     σX = √( Σ [ (x − μ)² · P(x) ] )
shortcut: σX = √( Σ [ x² · P(x) ] − μ² )
  1. P(x) = frequency ÷ total (if given counts).
  2. Mean: multiply each x by P(x), add.
  3. SD: (x − μ)², times P(x), add, square root.
  4. Graph: probability histogram — one bar centered on each x, height = P(x).
Q: "Is this a valid discrete probability distribution? x: 0,1,2,3,4 with P(x): 0.34, 0.21, 0.13, 0.04, 0.01."
A: each P(x) is between 0 and 1 ✓, but 0.34+0.21+0.13+0.04+0.01 = 0.73 ≠ 1 → NOT valid (probabilities must add to 1).
Q: "Games played in the Stanley Cup, X: x = 4 (freq 20), 5 (20), 6 (26), 7 (17). (a) Construct the probability distribution. (b) Graph it. (c) Compute and interpret the mean. (d) Compute the SD."
(a) total = 20+20+26+17 = 83 → P(4) = 20/83 = 0.2410, P(5) = 0.2410, P(6) = 26/83 = 0.3133, P(7) = 17/83 = 0.2048 (sum ≈ 1 ✓)
(b) bars at x = 4, 5, 6, 7 with heights 0.2410, 0.2410, 0.3133, 0.2048
(c) μ = 4(0.2410) + 5(0.2410) + 6(0.3133) + 7(0.2048)
  = 0.9640 + 1.2050 + 1.8798 + 1.4336 = 5.48 games
  → over many series, the Cup lasts about 5.48 games on average
(d) (4−5.48)²(0.2410) = 2.1904(0.2410) = 0.5279
  (5−5.48)²(0.2410) = 0.2304(0.2410) = 0.0555
  (6−5.48)²(0.3133) = 0.2704(0.3133) = 0.0847
  (7−5.48)²(0.2048) = 2.3104(0.2048) = 0.4732
  σ² = 1.1413 → σ = √1.1413 ≈ 1.07 games
Q: "Chuck-a-Luck profit: −$1 (0.5787), $1 (0.3472), $2 (0.0695), $3 (0.0046). Mean?" A: −0.5787 + 0.3472 + 0.1390 + 0.0138 = −$0.08 → lose 8¢ per game on average. Insurance: $100(0.9986) + (−$9,900)(0.0014) = 99.86 − 13.86 = $86 expected profit.

Binomial ★Q4

Binomial experiment = (1) fixed n trials, (2) independent, (3) two outcomes (success/failure), (4) same p every trial. X = # of successes.

P(x) = nCx · px · (1 − p)n − x    nCx = n!x!(n − x)!
μ = n·p     σ = √( n·p·(1 − p) )
Excel: =BINOM.DIST(x, n, p, FALSE) exactly x · TRUE = P(X ≤ x)

Q: "60% of U.S. women say the minimum driving age should be 18. Random sample of 10 women. (a) Exactly 3? (b) Fewer than 3? (c) Between 1 and 3 inclusive? (d) For a sample of 200, expected number and SD?"
n = 10, p = 0.60, 1 − p = 0.40
(a) P(3) = 10C3(0.6)3(0.4)7 = 120 · 0.216 · 0.0016384 = 0.0425
(b) P(X < 3) = P(0) + P(1) + P(2)
  P(0) = (0.4)10 = 0.0001 · P(1) = 10(0.6)(0.4)9 = 0.0016 · P(2) = 45(0.36)(0.4)8 = 0.0106
  = 0.0001 + 0.0016 + 0.0106 = 0.0123
(c) P(1 ≤ X ≤ 3) = P(1) + P(2) + P(3) = 0.0016 + 0.0106 + 0.0425 = 0.0547
(d) n = 200: μ = 200(0.60) = 120; σ = √(200·0.60·0.40) = √48 = 6.93
Q: "Binomial or not? (1) Roll a pair of dice 10 times, count 7s. (2) Select flights until 10 late ones are found. (3) Pick 4 of 30 students, count females."
A: (1) YES: n = 10, p = 6/36 = 1/6, x = 0…10. (2) NO: n not fixed. (3) NO: without replacement from 30, trials not independent (4/30 = 13% > 5%).
Q: "On-time rate 0.70, 4 flights. Build the distribution." A: P(0) = (0.3)⁴ = 0.0081 · P(1) = 4(0.7)(0.3)³ = 0.0756 · P(2) = 6(0.49)(0.09) = 0.2646 · P(3) = 4(0.343)(0.3) = 0.4116 · P(4) = (0.7)⁴ = 0.2401 (sum 1 ✓).
Q: "Free throws 95%, 3 shots: P(all 3)? P(less than 3)? mean & SD?" A: 0.95³ = 0.8574; 1 − 0.8574 = 0.1426; μ = 3(0.95) = 2.85; σ = √(3·0.95·0.05) = √0.1425 = 0.38.
Q: "72% prefer chocolate, n = 10: exactly 8? fewer than 3? at least 3?" A: 45(0.72)⁸(0.28)² = 0.2548; P(0)+P(1)+P(2) = 0.0010; 1 − 0.0010 = 0.9990.
Q: "Chuck-a-Luck SD?" A: μ = −0.0787; Σ(x − μ)²P(x) = 0.4912 + 0.4040 + 0.3003 + 0.0436 = 1.2391 → σ = $1.11.
  • Discrete vs continuous: number of pieces / colors / people → discrete; mass, diameter, time, temperature → continuous.
  • Expected value E(X) = μX: "in the long run, average of X per trial."

CH 6 — CONTINUOUS & NORMAL

Density curves & uniform ★Q5

  • Probability density function (pdf) = a curve where the AREA under it over an interval = the probability X is in that interval; total area = 1; curve ≥ 0.
  • P(X = one exact value) = 0, so P(a < X < b) = P(a ≤ X ≤ b).
  • Uniform on [a, b] = flat rectangle: every interval of the same length is equally likely.
Uniform height = 1b − a    P(c ≤ X ≤ d) = d − cb − a = (length of piece) × height
"P% within the next t" → t = P × (b − a)
Q: "Daytime temperature X is uniformly distributed between 70°F and 100°F. (a) Sketch/describe the pdf. (b) P(75 ≤ X ≤ 85)? (c) P(X < 80)?"
(a) rectangle from 70 to 100, height 1/(100 − 70) = 1/30 (area = 30 × 1/30 = 1)
(b) (85 − 75)/30 = 10/30 = 0.3333
(c) (80 − 70)/30 = 10/30 = 0.3333
Q: "Friend is 0 to 30 min late, uniform. P(10 to 20 min late)? There is a 20% chance they arrive within the next ___ min." A: 10/30 = 0.3333; 0.20 × 30 = 6 min. "Random number 0–10: P(exactly 4.35)?" A: 0. "P(between 2 and 5)?" A: 3/10 = 0.3.

Normal distribution

Normal = bell-shaped, symmetric, described by μ and σ. Properties: (1) symmetric about μ; (2) mean = median = mode = μ (highest point); (3) inflection points at μ ± σ; (4) total area = 1; (5) tails approach the axis but never touch; (6) Empirical Rule: 68% within 1σ, 95% within 2σ, 99.7% within 3σ; (7) area over an interval = proportion of the population in it = probability one random value is in it.

Standard normal Z = normal with μ = 0, σ = 1. Table V gives the area to the LEFT of z.

"Sketch the curve": draw a bell, write μ under the peak, tick marks at μ ± σ, μ ± 2σ, μ ± 3σ; mark the x value(s), shade the asked region, write the area in the shaded part.

z = x − μσ  (round z to 2 decimals)     x = μ + z·σ
LEFT of z: read table  ·  RIGHT of z: 1 − (left)  ·  BETWEEN: (left of z₂) − (left of z₁)
Negative z: area left of −z = 1 − (area left of +z)
  1. Draw the curve, mark μ, shade the region asked.
  2. Convert each x to z (2 decimals).
  3. Look up the area to the LEFT of each z (table below).
  4. Left → done. Right → 1 − area. Between → subtract the two lefts.
Q: "(a) Area to the left of z = −1.10. (b) Area between z = −0.60 and z = 1.45. (c) X normal with μ = 80, σ = 10; find P(70 < X < 95)."
(a) table: 0.1357
(b) left of 1.45 = 0.9265; left of −0.60 = 0.2743 → 0.9265 − 0.2743 = 0.6522
(c) z = (70 − 80)/10 = −1.00; z = (95 − 80)/10 = 1.50 → 0.9332 − 0.1587 = 0.7745

Interpreting an area; assessing normality

  • "Area to the right of 200 is 0.2903" means: (1) the proportion of the population above 200 is 0.2903, and (2) the probability a randomly selected person is above 200 is 0.2903.
  • Normal? Histogram: bell-shaped, one peak, roughly symmetric, few outliers. Normal probability plot: points close to a straight line → approximately normal.
  • Q: "Restaurant A wait times: tall on the left, long right tail. Restaurant B: symmetric hump. Which is normal?" A: B (bell-shaped); A is skewed right → not normal. "Greyhound times: plot points roughly on a line?" → approximately normal.

EXAM 1 SKILLS YOU STILL NEED

Mean: μ = Σx ÷ N (population)  ·  x̄ = Σx ÷ n (sample)
Median = middle of SORTED data (even n → average the two middles) · Mode = most frequent (none if no repeats)
Variance: σ² = Σ(x − μ)² ÷ N  ·  s² = Σ(x − x̄)² ÷ (n − 1)  ·  SD = √variance
z = x − μσ  (bigger z = relatively higher)  ·  Relative frequency = count ÷ total (= empirical probability) · % = RF × 100
Quartiles: Q₂ = median; Q₁/Q₃ = medians of the halves (odd n → leave the median out) · IQR = Q₃ − Q₁ · fences Q₁ − 1.5·IQR, Q₃ + 1.5·IQR → outside = outlier
Empirical Rule (bell-shaped): 68% within 1σ, 95% within 2σ, 99.7% within 3σ; bands 34 | 13.5 | 2.35 | 0.15 each side (IQ 85–130 → 34+34+13.5 = 81.5%)
  1. SD by hand: mean → each (x − mean) → square → add → ÷ N or ÷ (n − 1) → √.
  2. Calculator 1-Var Stats: σx = population SD, Sx = sample SD; variance = (unrounded SD)².

DON'T LOSE POINTS

  • "Or" → subtract the overlap once. "And" → the cell. "Given" → divide by the given group, not the grand total.
  • Check Σ P(x) = 1 before calling a distribution valid.
  • Sample vs. whole: binomial μ = np, σ = √(np(1−p)) — don't forget the √.
  • "Fewer than 3" stops at 2; "at least 3" = 1 − P(≤ 2); "at most" includes the number.
  • Uniform: probability = (length ÷ total width); never use z here.
  • Normal: ALWAYS convert to z (2 decimals) first; table = area to the LEFT.
  • "Above / more than" → 1 − left. "Between" → big area minus small area.
  • Percentile question → area → z (from inside the table) → x = μ + zσ.
  • Round probabilities to 4 decimals; show the formula every time.

Which rule? (Ch 4)

  • One event, equally likely → N(E)/N(S); from data → freq/total.
  • "OR" → add, subtract overlap. "AND" → multiply (P(F | E) if dependent).
  • "GIVEN / of those who…" → cell ÷ given group. "AT LEAST ONE" → 1 − P(none).
  • Counting: sequence → multiply; order matters → nPr; doesn't → nCr.
